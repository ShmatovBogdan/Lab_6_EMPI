# Лабораторна робота №6
# ТЕМА: Застосування емпіричних методів у програмній інженерії

# ХІД РОБОТИ
У ході виконання лабораторної роботи було досліджено набір даних JM1 із репозиторію PROMISE, який містить метрики програмного коду та інформацію про наявність дефектів у програмних модулях. Було реалізовано функцію для зчитування даних із файлу формату ARFF та перетворення їх у структуру DataFrame бібліотеки Pandas для подальшого аналізу. Далі виконано попередню обробку даних, зокрема перевірено наявність пропущених значень та виконано перетворення цільового стовпця defects у числовий формат, де значення true було замінено на 1, а false - на 0. Після цього проведено кореляційний аналіз між усіма числовими ознаками набору даних та цільовою змінною defects. На основі отриманих результатів побудовано візуалізації у вигляді стовпчикової діаграми та теплової карти кореляцій, що дозволило визначити найбільш значущі метрики. У результаті аналізу встановлено, що найбільший вплив на наявність дефектів у програмному коді мають характеристики, пов’язані з розміром та складністю програмних модулів, зокрема loc, v(g) та branchCount.
